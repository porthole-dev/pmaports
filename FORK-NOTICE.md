# About this fork

> **Unofficial.** Not affiliated with or endorsed by postmarketOS, Google, or
> Qualcomm. Do not report problems with this port to postmarketOS; open an
> issue here.
>
> **Experimental.** Flashing can brick the device or erase data. No warranty,
> see [COPYING](COPYING).
>
> **AI-assisted.** See [AI.md](AI.md).

This is an unofficial downstream fork of
[pmaports](https://gitlab.postmarketos.org/postmarketOS/pmaports), carrying the
porthole device ports. pmbootstrap's own documentation applies to building and
installing from it. Report problems at
<https://github.com/porthole-dev/pmaports/issues>.
